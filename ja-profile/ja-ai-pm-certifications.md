## 1. Duke University — Large Language Model Operations (LLMOps) *Specialization*  
**Completed: Nov 2025**

### Skills & Expertise Enabled

| Domain | Capabilities |
|--------|---------------|
| **LLM Fundamentals** | Understanding of foundation models, tokenization/encoding, fine-tuning, and retrieval-augmented generation (RAG). Ability to distinguish API-based vs embedded vs multi-model application architectures. |
| **Prompt Engineering** | Chain-of-thought prompting, few-shot examples, bookending, task breakdown, feedback loops, tone/persona setting, and context management. Techniques to avoid context overload and improve response quality. |
| **Multi-Platform LLMOps** | Operationalizing LLMs across Azure AI Services, AWS (Bedrock, SageMaker), Databricks, and local infrastructure (Ollama, vLLM, LM Studio). Hugging Face Model Hub familiarity. |
| **RAG & Vector Databases** | Designing chatbots and applications with personal/enterprise data using vector databases (Pinecone, Chroma, Weaviate). Document chunking, embedding, and retrieval strategies. |
| **LLM Frameworks** | LangChain, LlamaIndex, Semantic Kernel for building robust AI applications. |
| **Risk & Governance** | Awareness of LLM risks: incorrect/harmful outputs, hallucination, user trust issues, and mitigation strategies. |

### Portfolio-Ready Outcomes

- End-to-end LLM lifecycle: training, fine-tuning, deployment, monitoring, scaling
- Security, compliance, and cost-effective deployment best practices
- Hands-on experience deploying and managing LLMs across cloud and local environments
